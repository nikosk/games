# Art sources

The Enchanted Toyshop uses original game-bound illustrations generated with ByteDance Seedream 4.5 through OpenRouter on 2026-07-31.

| File | Source | Purpose |
|---|---|---|
| `images/toyshop-room.webp` | `source/toyshop-room.prompt.md` + `source/current-layout-empty-door-reference.png` | Main room background |
| `images/puzzle-panel.webp` | `source/puzzle-panel.prompt.md` + the finished room as a style reference | Reusable puzzle background |

The assets use an original preschool-cartoon toyshop with bold navy outlines, rounded shapes, and bright flat colours. They do not contain copied television characters or locations. No attribution requirement was supplied by the generation API.

Four successful image calls were made during this art pass for a total OpenRouter cost of **$0.16**. Two early watercolor drafts were rejected after the visual direction changed and are not kept in the project. Failed wrapper invocations were not charged.
